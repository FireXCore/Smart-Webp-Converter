# WordPress.org visual assets — v1.2.1

The authoritative visual sources are in [artwork/](../artwork/):
- `artwork/banner.svg` — responsive WordPress plugin header banner master
- `artwork/icon.svg` — square brand icon master
- `artwork/render_assets.py` — reproducibly creates WordPress.org PNG sizes

The CI workflow **WordPress plugin checks and package** runs a disposable WordPress installation, performs media upload tests, and captures two actual admin pages using a headless browser:

- `assets/screenshot-1.png`: actual **Smart WebP Converter Settings** page showing explicit destructive-mode confirmation.
- `assets/screenshot-2.png`: actual **Smart WebP Converter** dashboard showing only real conversion statistics.

It combines these actual screenshots with generated `banner-1544x500.png`, `banner-772x250.png`, `icon-256x256.png`, and `icon-128x128.png` in `smart-webp-converter-1.2.1-SVN.zip`. The package has `trunk/` and `assets/` at its root.

The screenshot step **must succeed** before the packaging job runs. Do not substitute AI-generated marketing mockups with fabricated conversion counts for published plugin screenshots.

Install ZIP: `smart-webp-converter-1.2.1.zip`.

SVN ZIP: `smart-webp-converter-1.2.1-SVN.zip`.

Both are generated by GitHub Actions after PHP lint, smoke tests, real WordPress integration and 1.1.0 upgrade acceptance. Updating GitHub does **not** publish or modify WordPress.org SVN. The public-release checklist remains Issue #2.
